# AI 评论分类 Pipeline 演示指南

前置条件：完成 `make preflight && make bootstrap && make build && make deploy && make demo`，打开页面显示的前端地址。所有业务作业都是固定 sleep 与结构化模拟输出。

1. 在 Pipeline 列表页为“小林的 AI 评论分类项目”创建干净演示副本，介绍业务边界：人工收集和标注是上游资产准备，在线服务和反馈闭环是未来平台能力。
2. 进入三栏编辑器：左侧是受控组件库，中间是 DAG，右侧是属性、输入、输出和运行详情。拖入节点并连线，确认连线显示 Artifact 类型，条件门禁显示“通过/拒绝”，端口类型不兼容时会被拒绝。演示删除节点会同步清理关联连线，清空画布可以撤销；再演示自动布局、适应画布、全屏和左右面板折叠。
3. 演示 15 节点业务链：已标注电商评论集、标签/隐私画像、数据质量门禁、清洗与三类数据集划分、BERT 与 RoBERTa 两路微调、独立测试集评测、排行榜、模型准入、登记、投诉评论推理冒烟、部署交接，以及通过/拒绝报告。
4. 点击两次“保存版本”，返回列表打开“版本历史”，确认 v1/v2 都可独立打开。删除整个本地 Pipeline 后，其运行记录仍可通过 Workflow 中的定义快照恢复。该存储和快照通道只是 PoC，后续分别由平台 Repository 和元数据存储替换。
5. 点击“校验”：若存在缺失输入或不兼容连线，问题列表可点击定位并高亮节点。训练节点参数按训练配置、资源、运行策略和 PoC 模拟参数分组；模拟 Accuracy/F1 明确不代表真实可配置结果。校验通过后点击“运行”，页面切换到独立运行视图。
6. 运行完成后确认 RoBERTa 候选位于排行榜第一名；查看 Accuracy、F1、推理延迟、候选相对基线差值和准入检查。投诉召回率属于评论分类模板未来可以扩展的业务指标，不进入通用节点契约。
7. 查看“投诉评论推理冒烟”输出：固定评论“客服一直不处理我的退款申请”模拟返回“投诉，置信度 0.96”。这不是真实模型推理。
8. 查看“推理部署交接”输出：`DeploymentRequestRef.status=READY_FOR_PLATFORM`、`adapterContract=InferenceDeploymentAdapter/v1`、`executionMode=SIMULATED_HANDOFF`。它证明交接契约可走通，但不会创建服务。
9. 将“评论分类模型准入”的 `minAccuracy` 改为 `0.99` 后重新运行：登记、推理冒烟和部署交接为 `SKIPPED`，拒绝报告成功，Workflow 本身仍为 `SUCCEEDED`。
10. 把两个微调节点的 `durationSeconds` 改为 30；停止其中一个节点，确认并行分支继续。Workflow 终态后从该节点重跑，确认只重跑它和下游。
11. 查看运行记录，确认默认按最新时间排序，可筛选业务运行、系统验证和状态；新运行显示版本号和 12 位定义摘要，并可恢复当时的 DAG。最后查看 Pipeline DSL 和 Workflow，确认只有固定 `templateRef`，不存在用户镜像、Shell、ServiceAccount 或原始 Argo YAML。

机器回归：`make smoke` 验证通过/拒绝门禁、推理冒烟和部署交接；`make node-smoke` 验证单节点停止、并行分支继续和局部重跑。
