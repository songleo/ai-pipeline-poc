# Pipeline PoC 三分钟演示指南

前置条件：完成 `make preflight && make bootstrap && make build && make deploy && make demo`，打开页面显示的前端地址。所有作业都是固定 sleep 与结构化模拟输出。

## 新手主路径

1. 在 Pipeline 列表页打开“新手入门：基础模型训练 Pipeline”，或点击“创建演示副本”。首页只把这个 4 节点模板标为“新手推荐”。
2. 介绍四步主流程：选择数据集、数据预处理、模型训练、模型评测。评测节点同时依赖模型和预处理后的数据，所以画布有 4 条类型化连线；这仍是一个四步 DAG，不是多余业务步骤。
3. 左侧组件库默认只显示上述 4 个基础组件。可新建空白 Pipeline，实际拖入组件并通过端口连线；需要展示门禁、双路训练或发布交接时再展开“高级组件”。
4. 点击节点查看中文参数和输入输出，点击“校验”，然后“保存版本”和“运行”。运行完成后，右侧只显示状态、时间、Accuracy、F1、延迟和模型输出，避免空的排行榜或门禁区域干扰新手。
5. 返回列表查看不可变版本，再从运行记录恢复当次 4 节点 DAG，证明“定义—运行—历史恢复”闭环。

## 可选专业扩展

第二个“专业示例：训练—评测—准入闭环”保留 15 节点通用示例，可用于说明数据质量门禁、双路训练/评测、排行榜、模型准入、登记、推理冒烟、部署交接和通过/拒绝报告。只有运行产生相应高级 Artifact 时，运行概览才显示门禁、排行榜、交接和 Lineage。

编辑器通用能力仍包括删除节点及关联连线、清空画布、撤销/重做、自动布局、适应画布、全屏、参数校验、单节点停止/重跑、Pipeline JSON 和固定白名单 Workflow。它们不需要在首次演示中逐项展开。

机器回归：`make smoke` 验证专业通过/拒绝门禁与失败/停止路径；浏览器回归优先验证新手模板的拖拽、连线、版本、运行结果和历史恢复。

边界：当前没有真实训练、真实 GPU、模型仓库或 `ai-platform` 调用。可复用边界是 DSL、Registry、Validator、Compiler、状态模型、版本快照和适配器契约；模拟作业与本地存储只服务 PoC。
